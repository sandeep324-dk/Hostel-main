# Hostel MERN – Hostel Management System

A full-stack hostel management application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- HTML5 and CSS3
- JWT Authentication

## Features

- Student Registration and Login
- Secure Authentication
- Hostel Management
- Student Management
- Complaint Management
- Student Dashboard
- Admin Dashboard

## Project Structure

```text
Hostel-MERN/
├── backend/
│   ├── controllers/
│   ├── models/
│   ├── routes/
│   └── index.js
└── client/
    ├── src/
    ├── public/
    └── package.json
```

## How to Run

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```

Configure your MongoDB connection and JWT secret in your local `.env` file before running.
